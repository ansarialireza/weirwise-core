# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Weirwise Core seriously.

If you believe you have found a security vulnerability in Weirwise Core:

1. **Do not disclose the issue publicly.**
2. Send an email to `security@weirwise.org` or report it via private GitHub Security Advisory.
3. Include detailed steps to reproduce the vulnerability.

We will acknowledge receipt within 48 hours and work with you to coordinate a responsible disclosure and patch.
